## Installation

First install PyTorch for your platform. https://pytorch.org/get-started/locally/. This software is GPU-enabled

Pytorch Version to Install:

    "torch>=2.7,<2.8",
    "torchvision>=0.22,<0.23",
    "torchaudio>=2.7,<2.8",

Then install giraffenn:

```bash
pip install giraffenn
```
